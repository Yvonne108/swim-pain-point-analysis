# 🏊‍♂️ AquaGuide - 智能游泳辅助小程序

AquaGuide 是一款致力于解决游泳初学者“换气困难”等核心痛点的智能体育辅助工具。本项目基于真实用户调研，打通了「数据洞察 -> 产品原型 -> 算法验证」的全链路，旨在通过 AI 视觉算法与智能硬件交互，为用户提供保姆级的游泳动作纠错与复盘体验。

# 💡 项目背景与痛点洞察 (Business Insight)

作为前国家一级游泳运动员，我深谙大众游泳初学者的痛点。本项目并未盲目开发，而是严格遵循产品经理的工作流，从数据出发挖掘需求。

- **数据驱动**：设计并回收 208 份有效问卷，使用 Python (Pandas) 完成数据去重、空值排查与异常值清洗。
- **精准定位**：通过 Matplotlib 构建可视化报表，精准提炼出占比高达 55.77% 的核心痛点 —— “换气困难”。
- **需求转化**：基于痛点，将用户需求系统转化为 3 大核心功能模块（渐进式脱敏、姿态传感器实时纠错、运动数据复盘）。

# 🚀 产品设计与核心功能 (Product Design)

产品规划了“手机端 (小程序) + 智能穿戴设备端”的双端交互体验：

1. **手机端 (小程序)**：运动数据看板、AI动作纠错复盘、训练计划推荐。
2. **手表端 (硬件交互)**：基于「姿态传感器实时纠错」概念的震动预警，实现实时呼吸节奏引导。

# 🛠️ 技术栈与架构 (Tech Stack)

本项目采用轻量级、高可用性的技术方案，跑通了从前端展示到后端处理及 AI 算法验证的完整闭环。

- **前端**：微信小程序
- **后端**：Flask (Python Web 框架)
- **数据分析**：Python (Pandas, Matplotlib)
- **AI 算法**：YOLOv8-Pose (计算机视觉)

# 🧠 AI 算法概念验证 (Algorithm Validation)

为了验证“AI 视觉动作识别”的技术可行性，本项目引入了 YOLOv8-Pose 算法进行核心链路跑通：

1. **关键点提取**：从视频流中提取人体 2D 骨骼关键点。
2. **动作规范性校验**：通过计算关节夹角（如手臂划水角度、头部抬升角度），设定阈值，实现动作规范性的初步识别验证。
3. **闭环验证**：成功跑通了“视频输入 -> 骨骼点提取 -> 角度计算 -> 纠错反馈”的完整 AI 识别 Demo。
