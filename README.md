# 大众游泳痛点数据验证与智能辅助软件需求分析

## 📌 项目背景
结合自身国家一级游泳运动员的实战经验，针对大众游泳者在日常训练中缺乏专业指导、动作易变形的痛点，从0到1完成用户调研、数据分析到产品功能定义的闭环。

## 📊 核心工作与成果
- **数据清洗与痛点挖掘**：设计并回收 208 份有效问卷，运用 Python (Pandas) 完成数据去重、空值排查与异常值清洗。精准提炼核心用户痛点（如“换气困难”占比达 55.77%）。
- **多维度需求拆解**：借助 Python (Matplotlib) 构建可视化报表，将用户痛点系统转化为“渐进式脱敏”、“姿态传感器实时纠错”等 3 大核心软件功能模块。
- **产品原型设计**：完成手机端（数据复盘）与手表端（震动预警）交互原型设计，并规划小程序+Flask后端技术实现路线。
- **AI算法概念验证**：探索引入 YOLOv8-Pose 算法提取人体2D骨骼关键点，计算关节夹角，实现动作规范性的初步识别验证。

## 🛠️ 技术栈与工具
- **数据处理**：Python (Pandas, Matplotlib)
- **AI探索**：YOLOv8-Pose
- **产品工具**：PPT (原型设计), 问卷星

## 💡 核心能力展示
- 用户视角的同理心与需求洞察能力
- 基于代码（Python）的数据清洗与自动化分析能力
- 从业务痛点向产品功能落地的逻辑拆解能力
